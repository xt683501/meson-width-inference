# Model-ready data tables

- [`meson-train.csv`](meson-train.csv): 370 training mesons, one central-mass row each. `width_mev` is the training label in MeV. This table includes the ten corrected training labels.
- [`meson-other-particles.csv`](meson-other-particles.csv): 47 archived records outside the 370-row training table, one central-mass row per record. Of these, 35 are main records and 12 are alternate encodings (marked by a trailing backtick); they are not 47 independent physical particles. `record_role`, `pdgid`, and `alias_of` identify related records. The `split` column preserves the source workbook's `val1` (8), `val2` (6), `val3` (21), and `vale` (12) codes for traceability; these codes are not a new partition of the public data.

Both tables use the model inputs described in [INPUT_FORMAT.md](../INPUT_FORMAT.md). `archived_width_mev` in the other-particles table reproduces the stored workbook number; **it is not always a measured point width**. Check `label_type`: `point` is a stored point label, `upper_limit` is a 95%-confidence upper bound, and `range` denotes a broad or model-dependent width. Do not calculate ordinary point relative error for an upper limit or a range. For current primary measurements and their uncertainties, consult the [Particle Data Group](https://pdg.lbl.gov/).

The rows were extracted from the project's corrected training workbook (`0902_500_train_corrected_v1.xlsx`, SHA-256 `33dcc74619b1f70f913f084aac84d7d047c9e2e47b9eec237970bdc5f61882e6`) by taking each record's central-mass row. The labels for particles outside the training table were retained from that archived workbook; the corrections affected training labels only. The CSV SHA-256 values are `f202c3b93b144fd0bfa0f85618034280c38bda0e4b7bfe94799007b8bab6da13` (training table) and `b8ec66c69b76c1b599dae834dd681ce10a6acd91091daf38aa14c9475778fa1b` (other-particles table). These compact files contain one row per record rather than the 501 mass draws per record used in the study; see the [paper](https://cpl.iphy.ac.cn/article/doi/10.1088/0256-307X/43/2/020201) for method details.
