# Model-ready data tables

- [`meson-train.csv`](meson-train.csv): 370 training mesons, one central-mass row each. `width_mev` is the training label in MeV. This table includes the ten corrected training labels.
- [`meson-validation.csv`](meson-validation.csv): all 47 archived non-training identities, one central-mass row each: `val1` 8, `val2` 6, `val3` 21, and `vale` 12 alternate records (marked by a trailing backtick). `record_role` distinguishes the 35 main validation records from the 12 alternates. `pdgid` and `alias_of` help identify related records.

Both tables use the model inputs described in [INPUT_FORMAT.md](../INPUT_FORMAT.md). `archived_width_mev` in the validation table reproduces the stored workbook number; **it is not always a measured point width**. Check `label_type`: `point` is a stored point label, `upper_limit` is a 95%-confidence upper bound, and `range` denotes a broad or model-dependent width. Do not calculate ordinary point relative error for an upper limit or a range. For current primary measurements and their uncertainties, consult the [Particle Data Group](https://pdg.lbl.gov/).

The rows were extracted from the project's corrected training workbook (`0902_500_train_corrected_v1.xlsx`, SHA-256 `33dcc74619b1f70f913f084aac84d7d047c9e2e47b9eec237970bdc5f61882e6`) by taking each identity's central-mass row. The validation labels were retained from that archived workbook; the corrections affected training labels only. The CSV SHA-256 values are `f202c3b93b144fd0bfa0f85618034280c38bda0e4b7bfe94799007b8bab6da13` (train) and `b8ec66c69b76c1b599dae834dd681ce10a6acd91091daf38aa14c9475778fa1b` (validation). These compact files contain one row per identity rather than the 501 mass draws per identity used in the study; see the [paper](https://cpl.iphy.ac.cn/article/doi/10.1088/0256-307X/43/2/020201) for method details.
